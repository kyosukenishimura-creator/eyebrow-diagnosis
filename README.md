# 似合う眉の形診断アプリ | B<AFTER SALON

## 概要
お客様の顔立ち・なりたい印象・ライフスタイルから、一番似合う眉の形を提案するWeb診断アプリです。

- **全12問** / 所要時間 約2分
- スマホ対応（レスポンシブ）
- B<AFTER SALONのブランドカラー（ブラック・ゴールド・オフホワイト）で統一

---

## 画面構成

| 画面 | 内容 |
|------|------|
| トップページ | ロゴ・タイトル・「診断をはじめる」ボタン |
| 質問画面 | プログレスバー・質問文・4択の選択肢・戻るボタン |
| 結果画面 | タイプ名・特徴・似合わせポイント・来店前チェック・WEB予約ボタン |

## 公開方法

### GitHub Pages
1. GitHubにリポジトリを作成
2. `index.html`, `style.css`, `diagnosis.js` をアップロード
3. Settings > Pages > Branch: main で公開

### Netlify / Vercel
1. リポジトリを接続
2. デプロイ設定不要（静的HTML）
3. 自動でURLが発行される
